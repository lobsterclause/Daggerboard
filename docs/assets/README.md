# README artwork

`daggerboard-banner.png` was generated with OpenAI image generation for the Daggerboard README.

The prompt combines a live service topology, propagated error signal, highlighted critical path, flame spans, latency scatter, and a persistent historical layer. It requested the exact title “DAGGERBOARD” and subtitle “See every trace. Find the critical path.” The final image was visually checked for observability relevance and legible text before replacing the README's uncommitted banner reference.
